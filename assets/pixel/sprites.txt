# Hand-authored pixel sprites. One source of truth for every in-game sprite.
#
#   @palette            one "<char> <rrggbb>" per line. 't' / 'T' are the team
#                       light/dark colours and are swapped per team at load.
#   @sprite <name> <frame> [frame1=<mode>:<row>]
#                       rows follow until the next blank line. '.' is clear.
#
# Modes derive an `idle1` from `idle0` so every unit gets a second idle frame
# without being redrawn:
#   breathe:N   rows above N lift by 1px, row N stretches (chest rises)
#   sway:N      rows above N shift right by 1px
#   float       the whole sprite lifts 1px
